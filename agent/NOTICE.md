# PixCake Agent provenance

This directory was started from the `agent/` directory of
`https://github.com/lfz-coder/MM-AniPet` (snapshot downloaded 2026-11-10,
repository main commit observed as `6b6cfd5`). The copied material has been
reduced to the Agent orchestration boundary and adapted for PixCake.

Pet identity, desktop automation, file/Shell tools, MCP configuration, RAG
storage, and unrelated UI state were removed. PixCake-specific tools and
protocols are new code and must remain subject to the PixCake architecture and
dependency policies.
