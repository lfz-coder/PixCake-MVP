## 1. 产品定义

像素蛋糕桌面版是面向商业摄影后期的本地优先影像工作台。它以项目管理原片，在图库里挑片，在精修里做非破坏性调色和人像，在创意里做图层和生成式处理，再导出或排版交付。

交付物是安装到操作系统里的桌面应用。Mac、Windows、鸿蒙各有自己的安装包和窗口，功能以本文为准。第一阶段先做 Mac 应用并完成验收，因为对照物就是这台 Mac 上的 test 版。Windows 与鸿蒙沿用同一套项目、参数和交互，只替换系统文件对话框、快捷键修饰键、安装与权限申请。

第一阶段的完成标准是：装好的 Mac 应用里，用户不看说明也能走完「登录 → 建项目 → 挑图 → 精修 → 预设与批量同步 → 创意生成 → 导出」，并且每个手册里点名的控件、规则、快捷键和计费行为都有对应实现。

### 2.3 手册冲突的裁决

同一行为出现两种写法时，按下面的顺序落地，并在验收时用 test 版再对一次。若 test 版与本裁决不同，改文档到与 test 版一致，不保留两套键。

1. 快捷键以《快捷键指南》为准，不以功能文里顺手写的按键为准。
2. 参考线按键采用指南：水平参考线 `Cmd/Ctrl + R`，垂直参考线 `Shift + R`，隐藏 `Option/Alt + R`。功能文里的 `R`、`Cmd + R` 创建、`Shift + R` 隐藏视为过时。
3. 批量同步按键采用指南：`Shift + Cmd/Ctrl + S`。`Cmd/Ctrl + C` 是复制效果，`Cmd/Ctrl + V` 是粘贴效果。批量文里把 `Ctrl + C` 写成同步的句子视为过时。
4. 色标按键采用指南：`6` 红、`7` 黄、`8` 绿、`9` 蓝。再按同一键取消。紫色只能用鼠标。功能文的颜色列举顺序不作为按键顺序。
5. `Cmd/Ctrl + N` 按页面分流：主页和项目列表是创建项目；图库是切换筛选视图。
6. `Cmd/Ctrl + T` 在指南里同时绑了「单视图」和「启动联机拍摄」。实现前用 test 版确认焦点规则。在确认前，图库视图切换使用该键切到单视图，精修右侧功能区使用该键启动联机拍摄。
7. 创意模块液化子工具「褶皱」是 `S`，只在液化工具激活时生效。修复工具激活时 `S` 是仿制图章。
8. 《AI 背景扩图》正文误把下一步写成点击「AI 老照片修复」。正确入口是「AI 背景扩图」。
9. 工具包展示名和计费表里的工具名有个别不一致。目录展示用工具包清单，扣点用计费表。搜索要能命中两边的名字。软件内如果与本文数字不同，以软件内当时显示为准，并回写本文。

## 3. 实现路线

本阶段只做桌面应用。应用有自己的窗口、菜单、本地数据库和画布。精修、图库、创意、导出都在这个应用里完成。不在本阶段做网页版。

应用内部按本地优先来拆：项目、参数、历史、缩略图和导出队列写在本机；原图留在用户原来的文件夹里。精修保存的是一张非破坏性参数文档。创意保存的是一份图层文档。生成式能力是可取消的任务，并写入点数账本。界面进程不直接承担导出和批量生成，这两类工作交给后台进程，避免大图导出时把窗口冻住。

### 3.1 窗口

应用同时只有一个主窗口。

- 未登录时，主窗口就是登录页。登录成功后同一窗口换成主页，不另开一个应用。
- 主页、图库、精修、创意是主窗口里的页面，不是各自独立的程序。
- 设置、导出、保存预设、AI 挑图规则、人脸修改、涂抹、液化、修复这些是主窗口上的模态层。模态层打开时，主窗口底下的画布不接收新的导入。
- 创意里的全屏（`F`）放大的是当前应用窗口里的画布。
- 个人中心里的购买、升级说明若要打开官网，调用系统浏览器打开那一个外部链接。关闭网页后，回到的仍是原来的应用窗口，当前项目和精修页面保持打开。

模态层至少包括：导出设置、导出列表、个人中心与设置、保存预设、导入预设、AI 挑图规则、年龄性别修改、各类涂抹、手动液化、手动修复、祛边、裁剪确认。手册写的「二级弹窗」就是这一层。

### 3.2 启动与单实例

同一用户同时只跑一个主实例。再次双击应用图标时，激活已有窗口，不再生出第二套数据库。

拖文件到应用图标时：

- Mac：拖到程序坞图标，或拖到访达里的 `.app`。
- Windows：拖到桌面快捷方式，或拖到正在运行的窗口。
- 鸿蒙：走系统「用此应用打开」把文件交给本应用。

拖入结果：

- 应用没启动，或已在后台且主窗口停在主页：启动或唤到前台，并按第 5.2 节新建项目。
- 主窗口停在任一模态层：不导入，窗口保持原样。
- 主窗口停在精修页：把照片追加进当前项目。

应用记住上次退出时的账号登录态。本机已有会话时直接进主页。退出登录只清会话，不删本地项目库。

### 3.3 文件、权限与导入

导入和导出使用操作系统文件对话框，可以选文件夹，也可以多选图片。应用要声明并在第一次用到时申请这些权限：

| 权限 | 用途 |
| --- | --- |
| 桌面、文稿、下载 | 读取这些目录里的原图并生成缩略图。用户拒绝时，该目录中的图片显示「格式不支持」或空缩略图，并提示去系统设置打开权限。 |
| 用户选定的其他文件夹 | 只访问这次对话框或拖放给出的路径。 |
| 可移除储存设备 | 为后续联机拍摄保留。本阶段不实现相机会话，但权限说明按联机拍摄来写。 |
| 控制访达（仅 Mac） | 「从磁盘删除」时删除源文件。用户拒绝时，这次删除改为只从项目移除并进入回收站，同时说明没有删掉磁盘文件。 |

导入原片支持 JPG、JPEG、PNG、TIF、TIFF、BMP，以及相机 RAW。RAW 扩展名清单随解码器配置下发，界面只要能标出 RAW。打不开的文件不进项目，并在导入结果里列出原因。证件照「我的背景」仍限制为 jpg、png、tif、bmp 且单张不超过 10MB。预设可导入 `.xmp`，滤镜可导入 CUBE。

原图不复制进应用包。应用只保存绝对路径、书签或系统授予的安全范围，以便重启后还能读。用户在访达里挪走或重命名原图后，项目里该图标成「原文件缺失」，参数文档保留，缩略图用上次缓存。原文件回到原路径后自动恢复。

### 3.4 进程

| 进程 | 职责 |
| --- | --- |
| 主进程 | 窗口、登录、项目库、快捷键、参数编辑、把预览请求发给渲染进程 |
| 渲染进程 | 缩略图、精修预览、创意画布合成。预览最长边 4000px |
| 导出进程 | 全分辨率导出、排版、打印提交。极速导出时，主进程拒绝新的编辑和预览请求 |
| 生成进程 | 创意 AI 任务的排队、进度、取消。取消规则见第 17 节 |

主进程崩溃后重新打开，已写入磁盘的项目和参数还在。导出进程崩溃只把对应任务标成失败，并允许重试，不回滚已经写完的文件。生成进程崩溃时，已扣的点按「生成中取消不退点」处理，任务标成失败。

### 3.5 自动保存

没有单独的「保存项目」命令。`Cmd/Ctrl + S` 打开导出列表，不承担保存。

滑杆、标记、裁剪、蒙版、预设应用在松手或确认后写入编辑文档。写盘间隔不超过 2 秒。应用被强制退出后，重新打开能看到最后一次写盘的效果。历史步骤在进程活着时可以逐步回退；进程结束后折叠成「上一次保存」，这一点不变。

### 3.6 应用菜单

系统菜单只重复应用里已经有的命令，不增加手册没写的修图功能。

- 应用菜单：关于、检查更新、设置、退出登录、退出。
- 文件：创建项目、打开项目、导入照片、导出、导出列表。
- 编辑：撤销、重做、复制效果、粘贴效果、删除、自定义快捷键。
- 视图：转到首页、图库、精修，网格、单视图、筛选视图，放大、缩小、默认尺寸。
- 窗口：最小化、缩放、把主窗口带到前台。

菜单项的快捷键与第 23 节同一张表。用户改了自定义快捷键后，菜单显示跟着改。

### 3.7 指针与画布

画布在应用内用指针事件驱动，不依赖网页滚动。

- 滚轮或触控板滚动移动画布；捏合或 `Cmd/Ctrl` 加滚轮缩放。`H` 为抓手。
- 滑杆可拖、可输入、可按第 23 节微调。输入框在应用内，回车确认，`Esc` 关闭当前模态层。
- 右键菜单用于手册里的全部右键动作：预设、样片、参考图、参考线、蒙版、图层、回收站、虚拟副本。
- 从系统文件管理器拖进主页导入区、画布、参考视图、样片库、背景库，目标区高亮，松手后按该区自己的规则接收。模态层打开时，拖到应用图标无效；拖到模态层内部的上传区仍然有效，例如导入样片、上传背景。
- 画布按系统缩放倍数渲染，1x 和 2x 屏上同一张图的取色和蒙版边缘对齐到同一图像坐标。

### 3.8 磁盘布局

应用数据放在系统规定的应用支持目录，不写进安装包：

| 路径 | 内容 |
| --- | --- |
| `db/` | 第 20 节的本地库 |
| `cache/thumbs/` | 缩略图和 4000px 预览缓存，可清除。清除后按原图重建 |
| `cache/exports/` | 未完成导出的临时文件。成功后删掉临时文件，只留用户选定目录里的成品 |
| `presets/` | 我的预设、口令导入结果 |
| `samples/` | 我的追色样片，计入 2000 张上限 |
| `materials/` | 我的滤镜 CUBE、天空、证件照背景、布景背景、水印图 |
| `creative/` | 图层文档、生成记录、`.tsq` |
| `logs/` | 诊断日志，不含原图 |

卸载应用时提供「同时删除本地项目库和缓存」的选项，默认不勾。不勾时只删程序，保留上述目录和用户原图。

### 3.9 安装、更新与退出

- Mac 第一阶段交付可安装的 `.app`，能放进程序坞。Windows 交付安装包。鸿蒙交付该系统的应用包。三者的项目文件不能靠「把网页存下来」互相打开，要靠本机数据库和原图路径。
- 个人中心显示当前版本，并提供升级。发现新版本后给出说明，用户确认后下载、替换应用并重启。更新不改已有项目库。
- 退出时若导出或生成仍在进行，先询问：等待完成，或终止任务后退出。终止导出不留下半张成品；终止生成按第 17 节的扣点规则。
- 极速导出开启期间，退出也走同一询问。该模式不因为队列暂时空闲而自己关闭。

### 3.10 模块边界

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| 壳层 | 主窗口、菜单、登录、导航、个人中心、消息、传输列表、导出列表、设置、单实例 | 账号服务、本机会话 |
| 项目库 | 项目、图片、标记、回收站、虚拟副本、原文件缺失状态 | 本地库、原文件 |
| 图库 | 网格、单视图、筛选视图、挑图、元数据 | 项目库 |
| 精修 | 画布、参数栈、蒙版、手动工具、前后对比 | 渲染进程、项目库 |
| 创意 | 图层、选区、官方 AI 工具、配方批量 | 精修当前像素、生成进程、点数账本 |
| 预设与同步 | 预设、样片、XMP、CUBE、效果复制 | 精修参数模型 |

## 4. 角色与主路径

角色：

- 摄影师或修图师：手机验证码、微信登录。
- 商家成员：商家账号登录。商家管理员上传的团队样片、一次购买后全员共享的工具包，作用在这个身份上。
- 未登录用户：只能停留在登录页。

主路径：

1. 登录。
2. 导入文件夹或图片，生成项目。项目名取第一个文件夹或第一张图片的名字。
3. 照片不少于 150 张时，询问是否去挑图。
4. 在图库或精修里打星、旗标、色标，筛出要修的照片。
5. 精修默认打开。调色、人像、背景、衣服按人物属性调整。
6. 保存预设，或同步到选中图片。
7. 需要生成式结果时进入创意，生成后「应用至精修」或「导出至本地」。
8. 导出。原图与其全部虚拟副本合计只计 1 张导出扣费。

成功标准：上述路径在无网预览已缓存原图时仍可打开项目和已有参数；需要账号、点数、云和生成的动作明确失败并给出原因。

## 5. 登录与壳层

### 5.1 登录

- 默认是手机号 + 6 位短信验证码。点击「获取验证码」后发送短信。
- 可切换到微信登录、商家账号登录。
- 帮助入口提供联系售后、查看快捷键。
- 登录成功进入主页。退出登录回到登录页，本地项目文件仍留在本机，再次登录同一账号后可见。

### 5.2 主页

左侧导航：主页、AI 工具箱、本地项目、云空间、工作流、选片交付、回收站。

主页同时展示三类项目：

- 本机创建的项目
- 已上传到云空间的项目，左上角有云标识
- 从云空间下载到本机的项目，左上角有云标识

本地项目页只展示本机创建的和从云下载到本机的项目。

顶部或全局区：搜索项目名或关键词、技术支持、个人中心、消息中心、传输列表、导出列表。

导入区提供「+ 照片导入」和「联机拍摄」。照片导入可选文件夹或图片，也接受拖入。拖到应用图标上时：

- 软件未启动，或已在后台且停在主页：启动并新建项目。
- 停在设置、导出等二级弹窗：不导入。
- 停在精修页：追加到当前项目，不新建项目。

多个文件夹或多张照片一起拖入时，项目名用第一个文件夹或第一张图片的名字。

项目列表支持全选、取消多选、删除。删除进回收站。

个人中心至少包含：剩余张数、已购买套餐、当前版本、升级软件、退出登录、创意点数明细入口、会员续费入口。直方图读数的显示开关也在设置里。

消息中心展示软件内消息。传输列表展示上传与下载任务。导出列表展示导出任务，并提供极速导出模式开关。

- 工作区切换：图库、精修、创意。进入项目默认精修。主页项目单击只选中，双击打开；再次打开时回到该项目上次所在的工作区（图库回到网格视图，精修打开上次选中的那张）。图库网格单击照片选中，双击在图库里切到单视图看大图，不进精修；进精修用顶部「精修」。（像素蛋糕-test 实测，见 evidence/2026-11-06-project-entry-observation.md；用户 2026-11-06 决定按真实程序。）
- 全局区在主页那些入口之外增加「导出」，导出当前选中图片。
- 搜索 `Cmd/Ctrl + F`：既能搜功能，也能搜当前项目图片文件名。功能结果点击后跳到功能位置并高亮。可跳转的范围是调色和人像的一级、二级功能，图像美化和衣物美化的一级功能，以及裁剪、液化、修复、历史记录。

### 6.1 标记

### 6.2 筛选

入口在图库和精修底部。多个条件同时生效时取交集。筛选设置可在专业模式和快捷模式之间切换。

条件：星级（大于等于、小于等于、等于，0–5）、旗标、色标、修图状态、导出状态、格式、构图。后几项都支持多选。「已筛选」旁的重置按钮清空全部条件。

### 6.3 排序

拍摄时间、编辑时间、星级、文件类型、文件大小、文件名。每种都可升序或降序。

### 6.4 显示状态

图库左上角可单独开关：显示 RAW、显示修图状态、显示导出状态。默认都开。精修缩略图默认显示这些标识。

每张图最多六类标识：上方 RAW、已导出、已编辑；下方旗标、星标、色标。

图库「全效果模式」：开则看效果图，关则看原图。只影响已经编辑过的图。

### 6.5 图库视图

- 网格：默认。左侧滑杆向左变多，每行最多 7 张；向右变少，最少 1 张。`=` / `-` 也缩放缩略图。
- 单视图：大图。
- 筛选视图：同屏对比多张，与缩略图选中状态实时同步。卡片上有 AI 精选标签、旗标、星标、色标和关闭按钮，关闭后剩余卡片动态补位。

图库侧栏：AI 挑图、预设、元数据。支持继续导入、筛选、排序、批量删除。

### 6.6 精修预览视图

切换在缩略图栏右侧。

- 单视图：只显示当前图。对比按钮或 `~` 看前后对比。快捷键指南里的空格也是查看对比。两个键都绑定到前后对比。
- 对比视图：原图与效果图并排。调色模式下还可选实时调色与全效果。
- 参考视图：参考图来自项目或外部。首次进入时，按住 `Option/Alt` 从缩略图拖入，或从外部拖入，或点「从本地导入」。缩略图右键「设为参考图」同样生效。AI 追色切换样片时，图钉可钉住参考图；默认不钉，参考图跟随样片。点图钉旁的关闭回到单视图。

对比视图、参考视图、涂抹页、创建自定义蒙版、年龄性别修改页、裁剪工具激活时，参考线自动隐藏且不能新建。

- 恢复项目时恢复其中被删图片和效果。
- 只恢复部分图片：双击进入项目，多选后点右上角「还原」。

虚拟副本：

- 图库或精修右键「创建虚拟副本」。多选时文案为「批量创建虚拟副本」。快捷键 `Cmd/Ctrl + '`。

- 同一原图的副本聚合显示，编号递增。
- 可以单独删副本。删原图时关联副本一起进回收站；恢复任一副本时原图一并恢复。

## 9. 预设

类型只有四种：

| 类型 | 包含 |
| --- | --- |
| 色彩 | 色彩调节，不含 AI 色彩 |
| AI 色彩 | AI 色彩风格或 AI 追色 |
| 人像 | 仅人像美化 |
| 组合 | 人像、色彩、AI 色彩、图像、衣物、裁剪中的多个模块 |

覆盖规则：同类型预设先后应用，后者替换前者。不同类型叠加。组合预设相对单类型预设也按「最后一次同类型为准」。调完色以后不要再套带色彩的预设，否则手动调色会被盖掉。产品必须按这个规则计算，并在套用前提示色彩将被覆盖。

新建：右下角「保存新预设」。名称不超过 20 字。选择或新建分类。类型按已用功能自动判断，允许手改。功能勾选默认包含 AI 色彩、色彩、人像、图像、衣物下的全部功能，可切到「已调整」「全选」「全部取消」或手改。保存后出现在「我的」。再次保存时可选「覆盖旧预设」。

管理：分类和预设都可拖拽排序，预设可拖到别的分类。右键重命名或删除。列表可按类型筛选，搜索框按名字搜，切换分类时同名预设分别可见。

分享：单个预设右键「分享预设」，一组右键「批量分享」，都生成口令。

导入：预设面板 `+` → 导入预设。口令导入要选分类。也可以从本地导入 `.xmp`。分享者版本更高时，提示升级后才能用。分享者已删除该预设时，导入失败。

预设列表快捷键 `Shift + S`。

## 10. 色彩调节

三大块：AI 色彩、色彩调节、局部调色。

### 10.1 AI 追色

面板包含：在 AI 追色和色彩风格之间切换、进入 AI 追色 2.0、导入样片、把当前图创建为样片、精准控制开关、局部追色、样片分组、重置、蒙版列表、程度。

样片分组：

- 推荐：AI 推荐、婚纱、婚礼跟拍、写真、儿童、风景。AI 推荐按光线、色彩、物体、场景打分，最多展示 20 组。匹配范围默认包含官方库和自己的样片，设置里可改范围。
- 团队样片：商家管理员上传。
- 我的样片：当前账号上传。

官方库按上述五大场景组织。自有样片两种导入：直接点「导入样片 AI 追色」或拖入；或进样片管理再导入并选分类。单次最多 1000 张。库上限 2000 张，满了必须先删。管理页支持排序、移动、新建分类、重命名、删除。

关闭精准控制：只调程度。全图有程度主滑杆，以及影调、色彩两个子滑杆，范围 0–200，默认 100。拉主滑杆时子滑杆跟着动。局部先选主体、宠物或背景的蒙版，或用自定义画笔，再调影调和色彩。

开启精准控制：追色结果写进全图和局部色彩参数，能看见数值。蒙版列表展示自动生成的蒙版，可进入后改参数，右键删除，也可新建。全图程度仍是 0–200，默认 100。

模型：极致更贴近样片；和谐更自然。

当前结果可「创建为样片」进「我的样片」。批量同步和保存预设必须勾选「AI 色彩调色」，同步时按每张图重新计算，不是把数值原样抄过去。

局部追色：指定样片区域和精修图区域，用智能选区或主体、宠物、背景蒙版，两边都选好后「开始追色」。局部追色不能批量同步。

### 10.2 色彩风格

程度 0–100，默认 100（2026-11-05 用户裁定按官方：test 版 AI 色彩风格程度实测上限 100）。应用后，色彩调节里被该风格写过的功能带重置标记。同一风格在不同照片上的参数可以不同，因为按该图动态计算。拉程度时其余参数联动。同步和存预设同样必须勾选「AI 色彩调色」，应用到别的图时重新匹配。

风格名称固定为：自然灵动 01、02、03；富士 NC；富士 NN；徕卡 M9；哈苏蓝；理光正片；理光负片；全能 400；纯真亮调 01；简约亮调 01；优雅中调 01；舒适怡然 01；质感光影 01、02；氛围萦绕 01、02、03；质感电影 01；唤彩胶片 01、02；清透明亮 01、02。

### 10.3 全图色彩工具

直方图横轴 0–255。鼠标在预览上时，直方图下可显示 RGB 和 Lab。右键直方图，或在个人中心设置里勾选要显示的读数。

AI 校准同时做白平衡和曝光，快捷键 `Cmd/Ctrl + U`。

多图色彩统一：以当前画布这张的白平衡和亮度为参考，统一所有选中图。建议放在调色最后。参考图自己不变。同组照片产生一条可一起撤销的历史。处理过程中可以做别的事，但这张图还在加载时按钮不可点。快捷键 `Shift + Cmd/Ctrl + G`。

配置文件：标准、质感、黑白、基础。自定义 `.xmp` 也列在这里。默认标准。AI 追色精准控制之后默认基础。黑白档会禁用影调里的鲜艳度和饱和度，并把 HSL 换成黑白组。

滤镜：推荐区是官方内置分类，手册写明约 11 个分类、近百个滤镜，但没有列出分类名。分类名和滤镜条目走素材配置，不在本文编造名字。右下角「更多」展开全部。每个滤镜有强度滑杆，可与其他调色参数叠加。我的：上传 CUBE，也可调强度。

白平衡：

- AI 校准白平衡，可批量，目标是接近色卡还原，并让同场景不同时间的照片一致。
- 自动白平衡。
- RAW 才有的预设：原照设置；自动；日光 5500/10；阴天 6500/10；阴影 7500/10；白炽灯 2850/0；荧光灯 3800/21；闪光灯 5500/0。非 RAW 的原照设置色温和色调都是 0。
- 吸管 `I`：点中性白或灰，据此改全图色温和色调。
- 色温：左冷右暖。色调：左偏绿，右偏洋红。

影调：AI 校准曝光、曝光、对比度、亮度、高光、阴影、白色、黑色、纹理、清晰度、祛雾、鲜艳度、饱和度。祛雾正向更干净，反向更朦胧。

色阶：输入色阶的黑、灰、白滑块，输出色阶的黑、白滑块。通道分 RGB、红、绿、蓝。RGB 下提供黑场吸管和白场吸管。

曲线：参数曲线含高光、亮调、暗调、阴影。另有 RGB、亮度、红、绿、蓝通道曲线，以及曲线吸管。通道切换是 `Option/Alt + 1` 到 `6`，这六个键不可自定义。方向键移动取点。

HSL：八个颜色各自的色相、饱和度、明亮度，加吸管。色相以红为例，向左偏洋红，向右偏橙。

色彩编辑器：吸管取样，色轮上收放范围。色彩平滑和亮度平滑默认联动，可解开。色相、饱和度、明亮度偏移都是 -100–100，默认 0。色彩均匀度分色相、饱和度、明亮度，向右更统一，向左层次更开。可显示所选范围，可反转范围。局部调色里使用时，蒙版外也显示为灰。

颜色分级：高光、阴影、中间调、全局。圆点离中心越远饱和度越高。混合控制交界平滑，平衡控制高光和阴影占比，明亮度控制选中区域明暗。

可选颜色：红、黄、绿、青、蓝、洋红、白、灰、黑。每个目标用青、洋红、黄、黑调节。相对按比例，绝对按绝对值，绝对更强。

细节：

- AI 降噪，有程度滑杆。可先多选再启用。JPG 还有降噪模型：标准、强力、自动。自动为默认。建议先降噪再 AI 追色；顺序反了要重算追色。
- 锐化，带半径和细节。
- 噪点消除，带细节和对比度。
- 减少杂色，带细节和平滑度。

颗粒：整体、阴影、中间调、高光、大小、粗糙度、颗粒色彩。

镜头调整：RAW 默认开启镜头矫正，可手调畸变和暗角，也可关掉自动后全手动。非 RAW 只手动。参数有畸变矫正、锁定裁剪、暗角、中点。总开关快捷键 `Shift + Cmd/Ctrl + R`。

透视矫正：AI 透视可设智能、水平、垂直。引导线最多 4 条，第 2 条松手即矫正。还有垂直、水平、旋转、长宽比、缩放、水平偏移、垂直偏移、辅助线、锁定剪裁。

校准：红、绿、蓝原色各自的色相和饱和度。

### 10.4 局部调色

人物：悬停「所有人」或某个人脸时，画布用红色显示范围。可选已有蒙版，或「联动调整」一次选多个，或「+ 创建蒙版」。

人物蒙版子项：全部人物/整个人、全部皮肤、面部、面部皮肤、脖子、身体皮肤、眉毛、眼白、眼瞳、嘴唇、牙齿、口腔、耳朵、头发。

衣物蒙版子项：全部衣服、上衣、内搭、连体衣（裙）、下装、头纱/帽子、手套、鞋子、背包、首饰、其他物品。全部衣服包含上衣、下装、连体衣（裙）、内搭、鞋子。其他物品包含头纱/帽子、手套、背包、首饰、领结、袜子。

这些部位的像素不在本仓库里训练，也不写训练脚本。蒙版图开始实现时，渲染进程和导出进程下载并调用许可允许本产品使用的预训练开源模型，把模型输出合并成上面的部位。预览用最长边 4000 的图，导出用全分辨率，合并规则同一套。所选权重没有单独输出的部位保持不可用，不用另一个部位冒充。换一份预训练权重时，部位名称和包含关系不变。模型文件和推理运行时不进入内核。

多个蒙版含同一子蒙版时，效果叠加。

宠物：所有宠物或单只。背景：全部背景、天空、草地、地面、礁石、水面、沙滩、山、建筑物。背景也可自定义。

`N` 进入。建议先用全身美型和面部重塑，再用手动液化。工具：向前变形 `W`、重建 `R`、平滑 `E`、旋转 `C`、褶皱 `Z`、膨胀 `B`、左推 `O`、冻结 `F`、解冻 `D`。`Shift + N` 轮换子工具。每个工具有大小、密度、压力、速率。`[` `]` 改大小，`Shift + [` `]` 改密度，`,` `.` 改压力，`Shift + ,` `.` 改速率。固定边缘锁住图像边缘。冻结和解冻时 `P` 显示蒙版，编辑区为红色。

## 14. AI 点修

`A` 进入，或从顶栏进入。

- 调色：色温、色调、曝光等基础项。定位更多滑杆会打开局部调色并滚到当前区域。若该图已 AI 追色，这里出现追色入口，只调当前选区的追色程度。

- 人像液化：悬停脸、颈、身体时出轮廓锚点，拖锚点塑形。

## 15. AI 挑图

入口：图库右侧「开始 AI 挑图」，或精修底部「去挑图」。一次导入不少于 150 张时弹出是否去挑图。

场景：通用、人像、证件照、活动、婚礼、家庭、儿童、学校、孕妇、私房。

AI 精选综合表情、姿态、美学和构图。可设入选数量上限，以及是否多选正脸。自动打标可选星标、色标或旗标。勾选「保留已设置的标签」后，已有星标、旗标、色标的图不再被改写。

检测，敏感度都是弱、标准、强：

- 闭眼。可排除大笑，或排除合影超过指定人数。
- 欠曝。
- 过曝。
- 模糊。可勾选「至少一张脸清晰则不算模糊」。
- 重复。敏感度是重复、标准、相似。重复组可进对比视图。

开始挑图后按规则打标并分组。右侧可按分组查看。回到精修后，用当时选择的打标方式就能筛出 AI 精选。

## 16. 创意模块

### 16.1 进入与离开

选中图片后点顶部「创意」，把选中图送入创意。各精修功能里的生成式入口也会直接打开对应工具。

完成后右上角二选一：

- 应用至精修。范围是「已创意编辑图片」或「当前选择图片」。方式是「更新原精修图」或「应用为新图」。新图扩展名 `.tsq`，出现在原图左侧。更新原图会保留效果、重置滑杆，不能再用重置效果回到原图，只能从历史选原图。
- 导出至本地。流程同精修导出，但不支持水印和排版印刷。

快捷键：导出至本地 `Shift + E`，应用至精修 `Cmd/Ctrl + E`，历史 `Shift + V`，全屏 `F`。

### 16.2 工作区

顶栏：显示比例、屏幕模式、抓手、移动图层、缩放、液化、污点修复、修补、仿制图章、矩形与椭圆选区、套索与选区画笔、裁剪。把照片拖进画布会变成新图层。

缩略图支持导入、筛选、排序。侧栏：AI 工具、历史记录、批量设计、帮助、新手引导、反馈。图层面板列出全部图层。

未选中图层时，属性面板改画布尺寸和分辨率。选中背景图层时可改对齐、位置、大小、旋转、翻转。双击图层缩略图进入该图层编辑。

### 16.3 图层

混合模式：正常、正片叠底、滤色、变亮、变暗。不透明度 0–100，默认 100。

可重命名、锁定、隐藏、复制、删除、新建组、以图层新建组、添加或删除图层蒙版。空白处右键可新建组。未选中图层时，添加蒙版、锁定、删除置灰。

图层蒙版可调密度和羽化，并用添加、减去画笔编辑。AI 祛路人图层可以切换已生成结果或重新生成，同时编辑它的蒙版。AI 超清图层可改对齐、位置、大小、不透明度、旋转。

快捷键见第 23 节创意部分。处于批量设计任务中的图不能编辑，也不能看历史和图层。

绘影工具包的多数工具生成两个图层：细节图层保留人物面部和身体，效果图层改全图。涂掉细节图层即可露出下面的效果。

### 16.4 批量设计

官方推荐配方至少覆盖：AI 老照片修复、AI 面部重绘、AI 祛路人、智能道具修复、AI 补草地、春日樱花、夏日晴空、秋天落叶、冬日雪景、证件照换衣服、AI 超清、镜头虚化、夕阳光、AI 补光、柔化阴影、自然光、发光。

自建配方：输入名称，添加一个或多个工具，拖动排序，可删除节点。部分节点可在「编辑」里改默认参数，部分不可以。执行前弹出预计点数，确认后在操作台看总进度和每张图的节点。可终止整个配方，或把某一张移出任务。

## 18. 批量同步

精修里先多选目标，再对当前图点「同步到选中图片」或按 `Shift + Cmd/Ctrl + S`。弹窗按一级功能展开，可只勾选二级功能。点「保存设置」后执行。

选择方式：全选、`Shift` 范围选、`Cmd/Ctrl` 加选。左下角显示已选张数。

复制效果 `Cmd/Ctrl + C` 与粘贴效果 `Cmd/Ctrl + V` 不打开这个勾选框，直接搬运当前效果。这两个键不可自定义。

不能同步的项目必须在勾选树里禁用并说明原因：局部追色、自定义画笔蒙版。

创意侧的批量不走这个弹窗，走第 16.4 节的配方。

## 19. 导出与打印

导出弹窗三个页：快速导出、自定设置、排版印刷。

快速导出：指定文件夹，或原始照片所在文件夹。显示总张数；若含未修改原图，同时显示原图张数。

自定设置：

- 存储位置同上。
- 指定文件夹时可「设为默认导出路径」。
- 指定文件夹时可「保留导入时的完整路径」。一次导入多个文件夹时，导出按原文件夹名重建。
- 原始文件夹时可「新建项目文件夹」，名称用项目名或原文件夹名。
- 格式：原始、JPG、TIFF，可记住默认格式。
- 品质二选一。文件大小限制是目标值，允许接近但不是硬截断。品质是 0–14 的整数，可用输入、档位或滑杆，越大越接近原画质。
- 色彩空间：可选转换为 sRGB。默认不改变原色彩空间。原图是 Adobe RGB 时，界面说明不要勾选，除非用户明确要 sRGB。

水印：上传图片，调位置、大小、不透明度。横图、竖图、方图分别记忆。点「水印同步」把当前构图的设置抄到另外两种。可同时导出一份无水印，不重复扣张数。

排版印刷：先在精修里裁到目标尺寸。再开照片排版，选证件照排版或普通照片排版。可调纸张方向、相纸尺寸、相纸分辨率、边距。边距分上下左右，单位有毫米、厘米、英寸。行数、列数、间隔只在证件照排版出现。可保存模板并在模板列表复用。本机有打印机时可开打印，选打印机、份数和打印设置，并与系统打印对话框联动。

极速导出：在导出列表左上角开启。开启后禁用编辑和预览，把算力让给导出。目标是比普通导出大约快 15%，这个比例是目标而不是保证。退出该模式后编辑和预览恢复。

导出任务进导出列表，可查看进度。失败要保留原因，允许对失败项重试。

## 20. 数据模型

本地库至少这些实体。原图像素不进数据库，数据库只存路径和派生数据。

- Account：登录身份、商家、剩余张数、创意点数、工具包订阅到期时间。
- Project：名称、创建来源（本地、云上传、云下载）、云标识、删除时间。
- Photo：项目、原文件路径、文件名、拍摄时间、编辑时间、大小、格式、RAW 标记、构图、星级、旗标、色标、修图状态、导出状态、AI 挑图分组和标签。
- VirtualCopy：指向原图，序号，自己的参数文档。
- EditDocument：一张图或一个副本的非破坏性参数。包含全图色彩、局部蒙版、人物属性覆盖、各模块滑杆、裁剪、手动工具结果、预设引用。
- Mask：类型（人物、衣物、宠物、背景、画笔、线性、径向、颜色、亮度、AI 选区）、父蒙版、加减、羽化、可见性。
- HistoryStep：文档内有序步骤。进程重启后折叠成一个「上一次保存」快照。
- Preset：类型、分类、名称、功能勾选、参数、口令、版本。
- Sample：追色样片，分组属于推荐、团队或我的。我的样片计数计入 2000 上限。
- CreativeDoc：从某张精修结果进入后的图层树、选区、生成记录。
- CreativeRecipe：有序工具节点和可编辑参数。
- ExportJob：目标、格式、品质、色彩空间、水印、排版、状态。
- CreditLedger：排队、加速、扣点、不退点的取消。
- Trash：项目或图片，删除时间，30 天后可清除。

`.tsq` 是创意应用为新图或 AI 完美表情保存出的副本文件，出现在原图左侧，有自己的编辑文档。文件放在第 3.8 节的 `creative/` 目录，同时在项目库里登记路径。

原图路径、编辑文档、缩略图缓存、导出成品是四份不同的数据。删缓存不删参数。删项目进回收站时不删原图。彻底删除项目时删的是应用数据；只有用户选了「从磁盘删除」才删原图。

## 21. 失败与边界

- 验证码错误、过期、未收到：停留登录页并说明。
- 二级弹窗打开时拖到应用图标：不导入，不新建空项目。
- 样片库已满或单次超过 1000：拒绝超出的部分并说明要先删除。
- 预设口令来自更高版本，或源预设已删除：不导入。
- 预设名超过 20 字：不允许保存。
- 第 6 个自定义工具栏：不允许创建。
- 收藏色超过 6 个：不允许再收藏。
- 全身美型判断会坏片：滑杆置灰。
- 纯色背景功能用在非纯色图上：无效果，而不是报错。
- 证件照换衣服遇到三人及以上：不生成，并说明只支持单人和双人。
- 面部重绘超过 5 人：必须手选，不能静默只处理前 5 个。
- 批量设计进行中：编辑、历史、图层入口禁用。
- 生成中取消：点不退。排队中取消：不扣点。
- 极速导出开启时：精修和预览不可用，直到关闭或队列结束。策略取「直到用户关闭」，队列结束不自动关闭。
- 关闭再打开：历史折叠。这是规格，不是缺陷。
- 从磁盘删除：确认框必须出现。只从项目删除则进回收站。Mac 上若没有访达控制权限，不能假装已经删掉源文件。
- 无打印设备：排版仍可导出，打印区不可用。打印对话框是系统对话框。
- 再次启动应用：激活已有实例，不打开第二套库。
- 原图被移走：该图保持在项目中并标成缺失，参数还在。
- 模态层打开时拖到应用图标：不导入。拖进模态层自己的上传区仍然有效。
- 更新应用：重启后项目库仍可打开，不要求用户重新导入照片。

## 22. 非功能需求

- 形态：安装型桌面应用。第一阶段验收物是 macOS 上的应用，对照 `pixcake-test` 9.3.0。Windows、鸿蒙使用同一项目库结构和同一套交互，系统差异只限文件对话框、修饰键、安装包和权限文案。
- 原图不被覆盖。除「从磁盘删除」和「更新原精修图」这两种明确动作外，调整只写编辑文档。
- 精修预览最长边 4000px。导出和创意文档使用完整分辨率。AI 超清应用回精修后变软必须在界面或帮助里能解释。
- 多图色彩统一、导出、创意生成都在后台进程跑。主窗口在这些任务进行时仍可切换已加载的照片。当前照片还没加载完时，依赖它的按钮不可点。
- 快捷键是应用命令，应用在前台时生效。可自定义的项必须能改、能恢复默认，并立刻反映到菜单。指南里标成不支持自定义的键不能进入自定义表。
- 点数、张数、工具包价格以下发配置为准，客户端不把本文数字写死到无法更新。本文数字是首版默认配置。配置缓存在本机，离线时用上次成功拉到的配置；没有缓存时用本文默认值。
- 30 天回收站按删除时间计算，不按日历月。应用下次启动时清掉到期项。
- 无网时可以打开本机项目、查看已缓存预览、改已下载素材能完成的参数。登录、短信、点数、生成、云传输、检查更新在无网时失败，并写明失败原因，不关掉当前项目。
- 主窗口在连续拖动一个滑杆时保持可操作。预览可以降级成分级刷新，松手后必须对上最终参数。导出成品以最终参数为准，不以中间那几帧预览为准。

## 24. 验收

每一条都要能在 Mac 上对照本文点选通过。AI 效果的像素不要求与官方模型逐点相同，但入口、档位、禁用条件、生成张数、扣点和图层结果必须相同。

1. 安装出的 Mac 应用可以放进程序坞。双击已在运行的应用只会把现有窗口带到前台。三种登录方式都能进入主页，帮助里能打开快捷键。购买和升级说明在系统浏览器里打开外部链接，应用窗口里的项目保持不动。
2. 拖到程序坞图标的三种情况符合第 3.2 节：主页新建项目、精修追加、模态层不导入。文件对话框导入的命名规则符合第 5.2 节。原图留在原处，重启后仍能打开。把原图挪走后，项目里标成缺失，参数还在。
3. 主页能区分本地项目和带云标识的项目。云、工作流、选片交付能打开本阶段规定的那一层页面。
4. 星级、旗标、色标、筛选交集、六种排序、三种显示状态、全效果模式、三种图库视图可用。
5. 单视图、对比视图、参考视图、钉住样片、前后对比可用。
6. 回收站 30 天、部分还原、彻底删除可用。虚拟副本继承效果、聚合、连带回收和 1 张计费成立。
7. 四种预设的替换和叠加符合第 9 节。口令分享、XMP 导入、20 字限制、覆盖旧预设可用。
8. AI 追色的两种模式、两种模型、0–200 程度、2000 张上限、局部追色不可同步，全部成立。
9. 色彩风格名称齐全。黑白配置文件会切换 HSL。RAW 白平衡预设数值符合第 10.3 节。
10. 人物、衣物、宠物、背景蒙版子项齐全。画笔蒙版不能同步、不能进预设。
11. 人物属性、单人调整锁定、人脸增删可用。
12. 第 11–13 节列出的滑杆和工具都能打开。坏片置灰、纯色功能对非纯色无效、涂抹可擦回。
13. 导入不少于 150 张会询问挑图。挑图场景、检测和「保留已有标签」成立。
14. AI 点修的两种选区、助手、调色跳转、锚点液化可用。
15. 创意图层混合模式、蒙版、应用至精修的两种写回、`.tsq` 位置符合第 16 节。
