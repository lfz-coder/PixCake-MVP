# Free 分组 HSL 实测证据

- 日期：2026-11-06
- 应用：像素蛋糕-test 9.3.0
- 页面：精修 > 色彩调整 > HSL
- 方法：Jarvis AX 读取控件；对每个可见 HSL 滑杆通过 AXSlider 写入并读回，越界以读回值保持边界值判定；每次结束恢复 0。

## 控件结构

HSL 面板包含 8 个颜色行：红色、橙色、黄色、绿色、浅绿色、蓝色、紫色、洋红色。每行一个 AXSlider；顶部有色相、饱和度、明亮度三种模式，当前选中色相。另有“在照片中拖动以调整HSL”复选框。

## 范围与步进

对 8 行共 8 个当前模式滑杆逐一验证：

| 检查项 | 结果 |
|---|---|
| 默认值 | 0 |
| 下限 | -100，写入后读回 -100 |
| 上限 | 100，写入后读回 100 |
| 越界下限 | -101 被拒绝，保持 -100 |
| 越界上限 | 101 被拒绝，保持 100 |
| 小数输入 | 0.5 读回 1，表明当前控件为整数步进 |
| 恢复 | 8 行均恢复为 0 |

本轮完整复核的是当前“色相”模式；饱和度和明亮度的三个模式切换及其 16 个对应滑杆尚未分别测量，因此不能据此注册全部 HSL 参数。

## 注册结论

暂不注册。已确认的是 HSL 色相模式的 UI 范围和步进；仍缺少饱和度/明亮度模式的独立实测、内部持久化参数 ID 及禁用条件。
