# 已注册色彩子分组与颗粒的参考像素实现（2026-11-06）

对象：`gpu/render/src/render_executor.cpp` 的参考绘制（renderd 预览走这条路）。用户 2026-11-06 决定先做已注册参数的像素实现，再补测未注册的分组。

## 来源说明

像素蛋糕没有公开这些调整的算法，本项目的公式都是**暂定**的：规则写在代码注释里，用测试钉住，不声称与像素蛋糕的结果一致。共同约束：

- 参数缺省时取参数模式的默认值（契约：参数模式是默认值的唯一来源），不在渲染器里另写一份。
- 每组在默认值处是恒等变换，并且先判断“是否偏离默认”再进入逐像素计算；没碰这些分组的文档逐位不变。
- 每个操作只读一次参数（`ColorGroups`、`Grain`），逐像素循环里不查表。

| 分组 | 规则（暂定） |
|---|---|
| 色阶（RGB 复合） | 输入黑/白拉伸、输出黑/白压缩，都按 0..255。灰场框是 −1..1（与 Photoshop 的 0.01..9.99 不同），映射为中间调伽马 10^灰场（0 不变，正值提亮中间调）。上排两框的最小间隔未测，不校验 |
| HSL | 八个色带中心 0/30/60/120/180/240/270/300°，色相落在相邻两带之间按线性权重（权重和为 1，无接缝）。色相 ±100 = ±30°；饱和度按 1+值 缩放色度；明亮度向白/黑移动最多一半余量，乘以像素饱和度（灰色不动） |
| 黑白配置文件 + 黑白混合 | 先取 Rec. 709 亮度（与 `luminance()` 同权重）；各色带的混合值按像素色度提亮/压暗该色相，灰色不变。黑白档下 HSL 不编译（参数模式禁用规则），所以只走这一支 |
| 可选颜色 | CMYK 可选颜色的形状：颜色目标按“主色领先量”（红/绿/蓝取 max−mid，青/洋红/黄取 mid−min），白/黑按与中灰的距离，中性按两端都接近中灰的程度。青作用于红通道、洋红于绿、黄于蓝；相对模式按已有油墨缩放，绝对模式直接加；黑色在三个通道一起加减油墨 |
| 颜色分级 | 阴影/中间调/高光是以亮度 0、0.5、1 为中心的三角权重，混合把半径从 0.5（混合 0）放宽到 1（混合 100）；全局处处为 1。每区按色相加去掉自身亮度的色度（不提亮），乘饱和度；明度最多移动四分之一。“平衡”未注册，不参与 |
| 颗粒（detail） | 晶格值噪声，格子大小随图像短边（≤4000 预览与全分辨率导出观感接近），粗糙度混入逐像素噪声，颗粒色彩把单色噪声混向分通道噪声；阴影/中间调/高光按亮度三角权重（半径 0.5）。按坐标确定，同一帧每次相同。颗粒效果为 0 时整步跳过 |

不画的：**色彩编辑器**三项偏移——目标颜色（吸管、范围）没有注册，偏移无作用对象；有非零偏移时给一条诊断“色彩编辑器还没有目标颜色参数，偏移暂不绘制”，滑杆保持禁用。**配置文件“质感”“基础”**需要配置文件资源，还没接入；下拉框里这两项不可选。
