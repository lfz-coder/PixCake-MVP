# 精修右侧功能区的层级（更正 2026-11-05 的平铺误读）

日期：2026-11-08
来源应用：`/Applications/pixcake-test.app`，像素蛋糕-test 9.3.0，精修页，打开一张 PNG（模特1【正】.png）
读取方式：Jarvis 执行机截图 + 辅助功能树（只读；AX 点击对该应用不可用，没有点开其他分组），加用户提供的四张截图。

## 结论

精修右侧从左到右是三块：

1. **预设栏**（由工具栏右侧「预设」开关）：标题「预设」、「推荐 / 我的」两个页签、「筛选 全部预设」、预设列表。
2. **模块面板**：一次只显示一个模块。标题是模块说明（调色 → 「色彩调节」），底部固定「保存新预设」「同步到选中图片」。
3. **图标栏**（最右竖排，可勾选按钮，辅助功能名/描述）：
   AI色彩、调色（色彩调节）、局部（局部调色） | 人像（人像美化）、图像（图像美化）、衣物（衣物美化）、后调色（后期调色）、裁剪（裁剪、旋转）、历史（历史记录）、联机（联机拍摄） | test、自定义（添加自定义工具栏）、帮助（帮助中心）。
   图标栏里**没有「宠物」**。

## 色彩调节页

自上而下：

- 标题「色彩调节」，右侧按钮「大师级色彩」。
- **直方图卡片**：三通道 RGB 分布（半透明填充，叠加处变亮）。下面一行平时是相机参数：「ISO -」「- mm」「F/-」「-秒」，右侧格式标签「PNG」——非 RAW 图没有 EXIF 就显示短横。鼠标放在画面上时，这一行换成指针下像素的「R 241  G 214  B 198」。RGB 还是 LAB 由菜单「视图 → 色彩读数 → RGB / LAB」选。
- 两个胶囊按钮：「AI 校准」（勾选型）、「多图色彩统一」。
- **可折叠分组**（每个分组标题栏高 48，左边小三角、分组名，部分带 Free/New 角标；勾选型，`value` 0 收起、1 展开）。顺序：
  AI色彩、配置文件、滤镜、白平衡、影调、色阶、曲线、HSL、色彩编辑器、颜色分级、可选颜色、细节、颗粒、镜头调整、透视矫正、校准、创意色彩。
  - 白平衡标题栏右侧：重置、「AI校准白平衡」；展开后：「白平衡 [自定义 ▾] [白平衡选择器(吸管)]」，再是「色温」「色调」两条滑杆（名字左上、数值右上、滑杆整行，色带分别是蓝→黄、绿→品红）。
  - 影调标题栏右侧：「AI校准曝光」。

## 2026-11-05 记录里的错误

| 当时写法 | 实际 |
| --- | --- |
| 40 个名称平铺在「色彩调节」组里 | 「色彩调节」是面板标题；名称分属预设栏、直方图卡片和 17 个折叠分组 |
| 「预设」「推荐」「我的」在色彩面板里 | 属于预设栏 |
| 「AI 校准」在「滤镜」后面 | 直方图下的按钮 |
| 「ISO -」等相机信息不进入界面 | 是直方图下的相机参数行，要显示 |
| 直方图下保留 RGB、Lab 两个读数位 | 同一行悬停时显示 R、G、B（或菜单选 LAB） |
| 九个模块按钮放在同一页 | 竖向图标栏，点一个显示一个 |

## 壳层现状（本次修复后）

- `apps/shell/refine_page.cpp`：预设栏 `refine-preset-column` | 模块面板 `refine-module-panel`（`QStackedWidget`，每个模块一页） | 图标栏 `refine-rail`（`QToolButton` 勾选组，对象名 `refine-rail-<编号>`）。选中的模块、展开的分组、预设栏开关在页面重建后保留。
- 色彩面板的分组来自 `ui/panels` 的 `refine_color_rows()`（`PanelRowKind::Section` 开始一个分组），分组用 `PixCakeFoldSection`（勾选型 `QToolButton` 标题 + 内容区），默认收起。
- 直方图卡片：`PixCakeHistogram`（QPainter 自绘）+ 相机参数行（还读不到 EXIF，一律短横；格式取文件扩展名）+ 悬停像素读数（`PixCakeImageView::onHoverPixel`，读的是画布当前显示的这一帧）。
- 还没做：分组标题栏的重置按钮、Free/New 角标、图标栏图标（`assets/refine-modules/<编号>.svg` 未提供，按钮暂时只显示文字）、LAB 读数、EXIF 读取、宠物模块的入口。局部、人像等模块页里的名称仍是平铺的禁用标签，层级没有逐个核对。
