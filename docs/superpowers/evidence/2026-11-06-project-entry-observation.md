# 进入项目与打开照片：像素蛋糕-test 实测（2026-11-06）

对象：`/Applications/pixcake-test.app`（像素蛋糕-test 9.3.0），项目“示例项目”（2 张：model.png、sample.dng）。
方式：Jarvis 执行机。项目卡片不在辅助功能树里，这个版本也没有合成输入，单击、双击用真实指针（用户同意）。
没有导入、没有改参数。开始前按用户同意退出了创意页（清空了 sample.dng 的创意编辑，精修不受影响）。

| 操作 | 结果 |
|---|---|
| 本地项目页单击项目卡片 | 只选中：卡片黄框，出现上传图标；页面不变 |
| 双击项目卡片（上次离开时在精修） | 直接进精修，打开上次那张（2/2 sample.dng） |
| 精修切到图库 | 网格视图，选中的仍是 sample.dng，“已选 1 张” |
| 图库网格单击照片 | 只选中：黄框，出现星级/旗标行，侧栏图片信息换成 model.png；仍在网格 |
| 图库网格双击照片 | 仍在图库，切到“单视图”（大图，底部缩略图条），不进精修 |
| 回主页，再双击同一项目（上次离开时在图库单视图） | 进图库，视图回到网格，选中 model.png |

结论：

1. 主页项目卡片：单击选中，双击打开。
2. 打开项目落在该项目上次所在的工作区（图库或精修），不是固定进精修，也不是固定进图库。图库的视图回到网格。从未打开过的项目、导入新建的项目落在哪里，这次没测（需求 5.3 写“进入项目默认精修”）。
3. 图库双击照片是图库内的单视图，进精修要点顶部“精修”。

与当前实现（提交 8779aee）的差异：主页单击项目就进入；进入后固定在图库；图库双击照片进精修。

辅助功能缺口（另报 Jarvis）：本地项目页的项目卡片不在树里；图库页按“首页”按钮的辅助功能动作无反应（精修页上有效）。

## 实现（2026-11-06，用户决定按真实程序）

- 主页项目列表改为 `QListWidget`（`home-projects`）：单击选中，双击（激活）打开。
- `ProjectSession::remember_place/last_place`：每个项目一行记录在 `<数据目录>/workspace/project-<编号>`（`library|refine <照片编号>`），是窗口状态不是项目记录，丢了就按默认（精修）；照片已不在该项目时忽略。
- `ShellController`：打开项目落在记住的工作区；图库落网格、只选中不打开照片；精修打开选中的（没有就第一张）。在图库、精修之间切换和改选中照片时更新记录；导入新建的项目进精修。
- 图库：网格单击选中（`select_photo`），双击切单视图（`request_view_photo`），大图是 renderd 按已提交编辑渲染的预览；“网格视图/单视图”按钮可切换（筛选视图还没做，按钮禁用）；底部缩略图条在单视图里换大图、在网格里选中。精修底部缩略图条单击仍是打开。
- 验证：`test_project_session`（默认精修、覆盖写、重开后读回、别的项目的照片编号不认）；`test_shell_app_import_flow`（图库单击只选中；双击进单视图且大图红色均值 229；主页单击项目不打开、双击回到图库网格且选中的是那张；切精修出帧；回主页再双击回到精修、红色均值 229；拖到应用图标三种情况照旧）。
