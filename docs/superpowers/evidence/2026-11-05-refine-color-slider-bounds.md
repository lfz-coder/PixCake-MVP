# 精修调色滑杆范围

日期：2026-11-05

这些名称来自像素蛋糕测试版 9.3.0 当时打开的调色面板。已看到的滑杆先按同一组数字填写：最小值 -100，最大值 100，步进 1，默认值 0。和这个不一样的行由人工改表。改完之前，不把表里的数字写进界面。

现场那张照片上的读数不是范围，也不是默认值，没有写进这张表。如果同一支滑杆在 RAW 和非 RAW 上范围不同，写在备注里。

2026-11-05 补充：色温、色调、曝光、对比度、亮度、高光、阴影、白色、黑色、纹理、清晰度、祛雾、鲜艳度、饱和度两边都可以拖。手册写了两个方向，范围保持最小值 -100、最大值 100、步进 1、默认值 0。
