# 原 Free 分组范围实测（进行中）：2026-11-05

目标应用：`/Applications/pixcake-test.app`（像素蛋糕-test 9.3.0，Jarvis app_key `Pixcake_mac`），项目 `test`，精修页，色彩调节面板。
依据：Free 条款修订计划（用户裁决：Free 只是标记，12 个分组都要实现；范围、步进、默认值必须来自实测，不得凭空补）。

## 测量方法（可复用）

- 这些数值框在 AX 树里是 `AXIncrementor`，`text` 是当前值，但 **`set_value` 写不进去**（`ax_value_mismatch`），要用真实键鼠：双击框 → `cmd+a` → 剪贴板粘贴值 → 回车（`mac_run_script`，`act_mode=pointer`）。
- 越界值**不会生效，框里保持上一个值**，所以“写入后读回是否等于所写值”就是接受/拒绝的判据。
- `AXIncrementor` 的 `index` 会随布局变化，**必须按 (x, y) 坐标找节点**再点击；不要用固定序号。
- 手柄拖动要点对手柄：色阶的灰场只有下方灰色三角能拖，上方圆点不响应。
- 键盘没点中输入框就发送按键，会落到别的控件上。每次点击后先确认进入编辑态再发键。
- 每测完一个框都写回原值。本轮结束时色阶各框已复位（0 / 255 / 0 / 0.00 / 255），并用截图核对。

## 色阶（精修 → 色彩调节 → 色阶）

面板上有 5 个数值框。上排两个（直方图上方）、下排三个（标签“黑场 / 灰场 / 白场”之下）。

| 框（位置） | 默认 | 接受的值 | 被拒绝的值 | 结论 |
| --- | --- | --- | --- | --- |
| 下排左（黑场） | 0 | 0、1、254、255 | 256、-1 | 整数 0–255 |
| 下排右（白场） | 255 | 254、100、1、0 | 256、-1 | 整数 0–255 |
| 下排中（灰场） | 0.00 | 0.5、1、-1（拖动到两端分别读到 0.96 和 -1.00） | 1.01、1.5、-1.01 | -1.00 到 1.00，显示两位小数 |
| 上排左 | 0 | 1、100 | 253、254、255、256、-1（右框为 255 时） | 整数，下限 0；上限受右框约束 |
| 上排右 | 255 | 254、100 | 2、1、0、-1、256（左框为 0 时） | 整数，上限 255；下限受左框约束 |

- 上排两个框互相约束：左框不能接近右框，右框不能接近左框，具体最小间隔没有测定（左 253 被拒，右 2 被拒，右 254 / 100 被接受）。**这条约束的确切规则未测完**，注册参数模式前要补一轮：固定右框 255，二分左框的最大接受值；固定左框 0，二分右框的最小接受值。
- 上、下两排各自对应“输入色阶”还是“输出色阶”，需要对照需求文档 §10.3 和手册确认后再命名；证据里只用位置称呼，不猜名字。
- 步进：数值框都是整数，灰场两位小数。滑杆（手柄）的步进没有测。
