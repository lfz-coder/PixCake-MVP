# 官方渐变蒙版观察（2026-11-07）

像素蛋糕-test 9.3.0，精修页“局部”面板，项目 test 的照片。只看不改参数；创建蒙版的操作已用 ⌘Z 撤销（蒙版列表回到只有“全图”），没有导出，张数没动（仍是 3 张，余额 10,551）。窗口原来有一部分在屏幕右侧之外，为点到右边的模块栏把窗口移到了屏幕左上（x=0）。

## 入口和蒙版模型
- 蒙版列表：顶部“创建新蒙版”，列表项是“<名称>”加子项（例如“自定义-1”下面是“线性渐变 1”“径向渐变 2”“径向渐变 1”），底下固定一项“全图”。一个蒙版可以包含多个子项，子项按“添加”（并集）或“减去”组合。
- “创建新蒙版”菜单：智能选区、自由选区、快速选区；画笔（K）、线性渐变（G）、径向渐变（⌘J）、颜色范围（⇧C）、亮度范围（L）；主体、宠物、背景。右侧面板“手动工具”里是同一组。
- 进入编辑蒙版后，面板里有：蒙版名、添加/减去、手动工具切换、该工具的参数（线性渐变只有“显示蒙版反相”开关；径向渐变多一个“羽化”滑杆，默认 50）、然后是这个蒙版自己的白平衡、影调……整套滑杆。也就是说**调整量属于蒙版**，一张照片可以有多个蒙版，每个有自己的一组滑杆（本版 MVP 一张照片只有一组）。
- 编辑蒙版时画面叠一层红色表示蒙版强度，缩略图是蒙版灰度图。

## 线性渐变
画布上从起点拖到终点：起点一侧强度 1，终点一侧强度 0，中间平滑过渡；起点之前保持 1，终点之后保持 0。实测拖动 (410,280)→(410,480)（屏幕坐标，图像缩放 74%）：红色在约 y=310 前接近满，到约 y=450 前消失，过渡带的可见范围略短于拖动距离（过渡曲线有平滑的两端）。缩略图上白在起点侧、黑在终点侧。

对应我们的参数：方向 = 起点→终点，过渡带长度 = 起点到终点的距离，中心 = 两点中点。我们的线性蒙版（强度 `0.5 - d/(2b)`，`b` 为半宽）在方向和强度上与此一致，`angle` 就是拖动方向（屏幕坐标，0 度向右、90 度向下），`size` 是过渡长度占画面对角线的百分比；柔和度对应官方两端的平滑，数值对应关系没有逐点测。

## 径向渐变
画布上从中心拖到外缘一个角：结果是**椭圆**，横向半径取拖动的水平距离，纵向半径取垂直距离（拖 (410,570)→(500,610)：外椭圆约 180 宽 80 高）。显示两层椭圆：外椭圆是强度降到 0 的边，内椭圆是强度满的边，羽化 50 时内椭圆约为外椭圆一半。椭圆四边各有一个调整手柄，中心一个移动手柄，内椭圆一个羽化手柄。纯水平拖动（纵向为 0）得到空蒙版（面积为 0）。

对应我们的参数：原来的径向是圆，现已改成椭圆：`gradient_size` 是横向半径、`gradient_ratio`（5..400）是纵向半径占横向的百分比，`gradient_feather` 是内椭圆缩进的比例。羽化默认 50 与官方一致。

## 没测
线性渐变没有羽化滑杆（面板只有反相），我们的线性带 `gradient_feather` 曲线柔和度是自加的；颜色范围、亮度范围、画笔、智能/自由/快速选区、蒙版反相的像素结果；多蒙版合成的顺序和“全图”的含义；手柄的拖动行为（改位置、改大小）；滑杆组随蒙版切换。
