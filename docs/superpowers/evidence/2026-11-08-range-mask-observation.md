# 官方颜色范围、亮度范围观察（像素蛋糕-test 9.3.0，2026-11-08）

只看交互，没有导出，不扣张数。项目 test（单张灰度人像）。

## 入口
局部调色 → 顶部标签“自定义” → “手动工具”：画笔(K)、线性渐变(G)、径向渐变(⌘J)、颜色范围(⇧C)、亮度范围(L)。点其中一个会新建蒙版并进入“编辑蒙版”页，蒙版自动叫“自定义-1”，第一次取样后列表里出现子项“颜色范围 1”。编辑页有“添加 / 减去”、三个标签（AI选区、智能主体、手动工具）。

## 颜色范围
- 提示：点击图片对颜色取样，按住 Shift 点击加样本，按住 Option/Alt 点击取消样本。
- 控件：“取样颜色”色块、“调整”滑杆（0–100，默认 50）、“显示蒙版反相”开关。
- 点牛仔裤一下，整条裤子被选中，红色叠层显示；背景和上衣不选。选区是软的。

## 亮度范围
- 提示：单击照片对明亮度取样；单击并拖动对一系列值取样。
- 控件：“选择明亮度”范围条 0/0 到 100/100（两端有三角手柄，条上有取样点）、“显示明亮度图”开关、“显示蒙版反相”开关。

## 尚未核对
调整=50 对应的颜色距离阈值、软边宽度、多样本合并规则、亮度范围手柄的羽化；这些要对比像素才能定，下一步用导出前的叠层截图量。

## 测量结果（2026-11-08，只在预览里量，没有导出，不扣张数）

方法：在“颜色范围”下取样 test 项目那张图（`模特1【正】.png`，1024×1536）牛仔裤上一点，取样色 RGB≈(123,141,163)；把“调整”分别设为 1、25、50、75、100，各截一张同区域的 2 倍图。预览把图显示成灰度并盖红色叠层，用 R−(G+B)/2 当选区强度（除以 90 近似成 0–1，最亮处略超 1，只当相对量）。再把原图缩放到同样大小，算每个像素到取样色的 Lab 距离，按距离分箱取叠层强度的中位数。

### 颜色范围：强度与 Lab 距离（除以 1.2 归一，约值）

| 距离(Lab) | 调整=1 | 25 | 50 | 75 | 100 |
|---|---|---|---|---|---|
| 0–5 | 0.80 | 0.91 | 0.97 | 0.99 | 1.00 |
| 5–10 | 0.54 | 0.76 | 0.87 | 0.93 | 0.95 |
| 10–15 | 0.23 | 0.53 | 0.72 | 0.83 | 0.88 |
| 15–20 | 0.03 | 0.28 | 0.54 | 0.70 | 0.78 |
| 20–25 | 0 | 0.11 | 0.38 | 0.56 | 0.68 |
| 25–30 | 0 | 0.02 | 0.23 | 0.44 | 0.57 |
| 30–40 | 0 | 0 | 0.01 | 0.15 | 0.30 |
| 40–50 | 0 | 0 | 0 | 0.08 | 0.22 |
| 50–60 | 0 | 0 | 0 | 0.01 | 0.08 |

结论：
- 选区强度随 Lab 三维距离单调下降，只看色度(a,b)不行（亮度也参与）。所以是“颜色距离”，不是只比色相。
- 调整的取值是 1–100（滑杆最小 1，不是 0）。
- 强度从 1 下降到 0 的距离随调整变大：约 18(1)、26(25)、32–34(50)、45(75)、58(100)；近似 T(v) = 18 + 0.4·v。
- 近似模型：alpha = clamp(1 − d_Lab / T(v), 0, 1)。50 附近真实曲线比线性更凸（偏宽），线性误差约 0.1–0.15，先用它，之后可以改成平滑曲线。
- 取样取的是一小片的平均色，不是单个像素（缩放后单像素差异大，用 7×7 均值与官方吻合）。

### 亮度范围
- 在牛仔裤上单击，范围条显示 `20/45` 与 `65/90`：四个值构成梯形。20 以下不选，20→45 渐变上升，45→65 全选，65→90 渐变下降，90 以上不选。取样点的亮度约 55%（RGB(123,141,163) 的亮度≈55），45 和 65 在它两边各 10，20 和 90 各 35。
- 条上有两个三角手柄（外侧 20 和 90，可拖动改羽化外沿），条上有取样点标记；“显示明亮度图”开关，“显示蒙版反相”开关。
- 一个蒙版里可以有多个子项（这次是“亮度范围 1”和“颜色范围 1”），叠层是它们的并集（添加）。

### 仍未量
- 亮度范围手柄拖动后内外沿的联动方式（是否内侧跟着动）；拖动取样一系列值时范围怎么算。
- 颜色范围多样本（Shift 加、Option 减）怎么合并；Lab 之外的可能性（官方也许用别的色彩空间）。
- “显示蒙版反相”开关只是显示还是真反相选区（先按显示处理）。

## 补测：显示蒙版反相（2026-11-08）
选中“亮度范围 1”（20/45/65/90，和“颜色范围 1”并集）打开“显示蒙版反相”：叠层整体翻转——背景、暗发、最亮的衣服变红，脸和中间亮度的衣服变淡；蒙版缩略图也变成几乎全白。和“这个子项取 1−选区，再与别的子项合成”一致，所以它是真的反转选区，不只是改显示。开关属于单个子项（每个子项都有）。关闭后恢复原样。颜色范围多样本（Shift/Option）还没量。
