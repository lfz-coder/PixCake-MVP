# 像素蛋糕-test 导出弹窗观察（2026-11-06）

对象：`/Applications/pixcake-test.app` 9.3.0，项目“示例项目”图库网格，选中第 1 张（model.png，原图未修）。Jarvis AX 读取；展开折叠区、打开下拉框、拖滚动条用了真实鼠标（用户同意：只展开和看下拉，不改选择、不导出），下拉框都用 Esc 收起，最后按“取消”关闭弹窗。没有导出，没有改任何设置。

## 入口

图库页右上角黄色“导出”按钮（AX 按得动）→ 模态窗口 `ExportDialog`，三个页签：快速导出、自定设置、排版印刷（单选按钮，AX 按得动）。

## 快速导出（480×449）

- 标题“选择一个预设应用到 **1** 张图片并导出”（数字是选中张数）。
- 三个统计按钮：精修效果图(0)（置灰）、免费效果图(0)（置灰）、原图(1)；下方提示“导出精修效果/免费效果为预估数，最终以导出明细为准”。
- 预设：下拉框，占位“请选择一个预设”。
- 导出至：下拉框（指定文件夹 / 原始照片所在的文件夹），下面是路径框 `/Users/lifangzai/Resource/images/示例项目_导出` 和选择文件夹按钮。默认文件夹名是“项目名_导出”。
- “上传选片交付”勾选框（New，带问号说明“将导出图上传到云端，用于在线选片或交付照片”），默认不勾。
- 底部：取消、导出（黄色）。

## 自定设置（902×650）

左侧：预览（缩放“40%”下拉、“合适”），下方筛选勾选：所有导出图片(1)（勾）、精修效果图(0)、免费效果图(0)、原图(1)，再下是缩略图条（标“原图”和序号）。

右侧（可滚动；滚轮不动，只能拖滚动条）：

- 同快速导出：标题、预设、导出至 + 路径、上传选片交付。
- **高级设置**（折叠，默认收起）：
  - 导出位置：设为默认导出路径（勾）、新建项目文件夹存储（勾）、保留导入时的完整路径（不勾）。
  - 图片格式：下拉框，选项 **原始格式 / JPG / TIFF8位 / TIFF16位**，默认原始格式；“设为默认格式”勾选框。
  - 品质（jpg）：二选一单选——“文件大小限制”（问号说明；数值框 10.00 MB，未选时置灰）/“品质”（默认选中）：数值框 **12**，档位下拉 **低 / 中 / 高 / 最佳**（12 显示为“最佳”），下面一条“小文件—大文件”滑杆（值 12）。原始格式下这一组也显示。
  - 色彩空间：勾选框“转换为sRGB”，默认不勾。
  - 保留叠加层：开关，默认关。
- **水印**（折叠 + 开关，默认关；关时内容置灰）：横图 / 竖图 / 方图 三个页签（当前图对应的一个选中）、“水印同步”按钮；上传框“点击上传素材 / 支持JPG/PNG格式，单张不超10MB”；旋转（逆时针、顺时针按钮）；定位（3×3 九宫格）；大小 10（滑杆+数值）；“合适”开关；不透明度 100；水平位置 3；垂直位置 3；“同时导出无水印图片”勾选框（问号说明）。

## 排版印刷

右侧“照片排版”折叠 + 开关（默认关，关时全部置灰）：模版列表（推荐）、“将下方设置新建为模板 / 保存模版”、证件照排版（选中）/ 普通照片排版、纸张方向（横 / 竖两个按钮）、相纸下拉“6寸相纸 152*102mm”、相纸分辨率 300 像素/英寸、行数 1、列数 1、间隔 10（滑杆）、边距（标尺单位：毫米；上 0、下 0、左 0、右 0 滑杆）、最下方“打印”开关。左侧预览与自定设置相同。

## 预设下拉

两组，各带子菜单：我的预设 >、推荐预设 >（子菜单未展开）。

## 与需求第 19 节对照

- 一致：三页结构；指定文件夹 / 原始文件夹；设为默认导出路径、保留导入时的完整路径、新建项目文件夹；格式可记住默认；品质二选一（文件大小限制 / 品质 0–14）；转换为 sRGB 默认不勾；水印横竖方三套与“水印同步”、同时导出无水印；排版字段。
- 需求没写、实测有：TIFF 分 8 位与 16 位；品质档位 低/中/高/最佳 与数值联动；默认品质 12；“保留叠加层”；“上传选片交付”；预设下拉在导出弹窗里；文件大小限制默认 10 MB；水印的旋转、九宫格定位、“合适”开关与默认值。
- 档位与数值的对应（低/中/高 各对应几）没测：只看到 12 = 最佳，改数值属于改设置，本次不做。
