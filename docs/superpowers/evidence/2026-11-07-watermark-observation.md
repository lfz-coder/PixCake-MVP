# 像素蛋糕-test 导出水印观察（2026-11-07）

对象：`/Applications/pixcake-test.app` 9.3.0。用户同意：用真实鼠标，打开水印开关，上传测试素材，导出一张。

- 用了哪些照片：
  - 方图：“示例项目”中选中的一张透明 PNG，在图库里打开导出弹窗；
  - 竖图：“test”项目的“模特1【正】.png”，1024×1536，免费效果图，在精修页打开导出弹窗。
- 测试素材（纯色 PNG，便于量边界）：
  - 红色 400×200；
  - 上红下蓝 200×400，用来看旋转方向；
  - 绿色 300×100。
- 怎么量：
  - 预览：对弹窗左侧预览区截原分辨率 PNG（2 像素/点），按颜色找水印的外框；
  - 成品：用 ImageIO 读导出的 PNG，同样找外框。

## 规则（预览与成品一致）

**大小**：
- 滑杆范围 0–100，默认 10。
- 先按素材原始方向缩放，使素材**短边 = 图片长边 × 大小%**，长边按素材比例缩放；然后再旋转。

| 测量 | 结果 |
| --- | --- |
| 方图 814 像素，红色 400×200，大小 10 | 82×41 |
| 竖图成品 1024×1536，绿色 300×100（3:1） | 461×154，短边 154 = 1536 的 10.03%，长边正好是短边的 3 倍 |
| 竖图预览 | 短边是图高的 10.07%，是图宽的 15% |

竖图上，短边对的是图高，不是图宽。如果“大小”按面积算，3:1 素材的短边应是 66 像素，实际是 82，所以排除面积。
- **未核实**：横图上到底对的是图高还是长边。手头没有横图照片，本项目按长边做。

**定位**：
- 3×3 九宫格，指定水印贴哪个角、哪条边或中心。默认是右上。
- 选格子会重置两个位置值：
  - 角上的格子：水平和垂直都是 3；
  - 左中、右中：水平 3，垂直 0；
  - 上中、下中：水平 0，垂直 3（按对称推断，没有实际点过）；
  - 中间：都是 0。

**水平位置 / 垂直位置**：
- 范围 -100 到 100，滑杆从中间往两边走。
- 数值是水印到贴靠那条边的距离，分别按图宽和图高的百分比算，正数往画面里移，负数往画面外移。
- 实测：
  - 水平 50 时，右边距 204/407（50%）；
  - 水平 100 或 -100 时，水印完全出了画面；
  - 竖图成品，右边距是图宽的 3.03%，上边距是图高的 2.99%；
  - 中格时水印正好居中。
- 超出画面的部分被裁掉。

**旋转**：
- 逆时针、顺时针两个按钮，每次转 90°。
- 上红下蓝的素材按一次顺时针后，红色在右边，说明确实是顺时针转。
- 旋转按页签分别记住。

**合适**：
- 开关，默认关。
- 打开后“大小”置灰，水印按比例缩放到正好放进画面（实测方图上宽度等于图宽）。
- 水印宽度占满画面时，水平位置不再起作用；垂直位置仍是 3%。

**不透明度**：0–100，默认 100。
- 不透明度 50 时，预览里的水印半透明。成品没有在 50 下量过。
- 不透明度 100 时，成品颜色和素材完全一样（0, 192, 0）。

**横图 / 竖图 / 方图页签**：
- 当前照片的方向决定选中哪一个；在竖图照片上点“方图”切不过去。
- 素材三种图共用：在方图页签上传后，竖图页签里也是同一张素材。
- 旋转、定位、位置等按页签分别记住。
- “水印同步”按钮没有点。

**开关**：
- 全局设置，会被记住。关掉后重开弹窗，仍是关闭。

**素材**：
- 上传框写“支持JPG/PNG格式，单张不超10MB”。
- 上传后显示缩略图，悬停出现“替换”，点击重新选择文件。
- 素材的透明部分保持透明。
