# 创意色彩“程度”实测证据

- 日期：2026-11-06
- 应用：像素蛋糕-test 9.3.0
- 页面：精修 > 色彩调节 > AI色彩 > 程度
- 当前样本：已选择的 AI 色彩风格，当前值 64。

## 实测

通过 Jarvis AXSlider 读写并读回：

| 写入 | 读回/结果 |
|---:|---|
| 0 | 0，接受 |
| 200 | 100，越过上限，未提交 |
| 201 | 100，越过上限，未提交 |
| -1 | 0，越过下限，未提交 |
| 恢复 64 | 64 |

因此当前“程度”滑杆的实测 UI 范围为整数 0–100，当前样本值为 64。此前资料中出现的 0–200 不能用于本控件，可能对应其他模式或旧版本。

## 注册结论

暂不注册。还缺少不同 AI 色彩风格切换后的持久化参数 ID 与默认值确认。
