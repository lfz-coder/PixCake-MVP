# Kernel 手动笔触会话闭环计划

日期：2026-11-05

## 背景和审计结论

架构第 6.10 节规定，液化、污点修复、修补、仿制图章、涂抹擦回和祛边的笔触先由
模态会话持有；确认后才形成手动增量并提交文档，取消不能改变文档。修复、仿制和
祛边的重放失败必须保留原增量并标成失效，禁止静默删除。现有 `EditDocument` 已有
手动增量引用，但缺少负责会话生命周期、笔触身份和重放失败语义的 `kernel/manual`
边界。

本计划只冻结这些内核数据和状态转换，不实现像素修复、液化网格计算、OpenGL、UI
模态层、文档写盘或能力编译。确认结果由上层命令入口拿去提交文档；会话自身不直接
改文档，保证取消天然没有文档副作用。

## 实现任务

### Task 1：冻结笔触和会话身份 `[x]`

- 新增手动工具种类、图像坐标/源点、笔触记录、提交结果和会话状态类型。
- 会话绑定图片编号和基准修订号；标识为空、含 NUL、点集为空或坐标不是有限数时拒绝。
- 修复、修补和仿制图章可携带源点；液化、涂抹擦回和祛边保留各自笔触数据，不复制到能力对象。

### Task 2：实现追加、确认和取消 `[x]`

- 只允许打开会话追加笔触，拒绝跨图片、过期修订、重复笔触编号和非法状态。
- 确认返回完整的已提交增量快照并关闭会话；空会话不能确认。
- 取消关闭并丢弃未确认笔触；会话不调用 `EditDocument`，因此不会改变文档修订或引用。

### Task 3：实现重放失败保留语义 `[x]`

- 已确认会话可把指定笔触标记为重放失效，原始点、源点和身份仍可读取。
- 标记操作幂等；未知笔触和已取消会话返回状态冲突，不删除任何记录。
- 对外只返回数据和状态，不假装完成像素重放；实际重放由后续 `manual.*` 能力负责。

### Task 4：测试、门禁和证据 `[x]`

- 覆盖身份校验、追加顺序、确认快照、取消无提交、重放失效保留和架构依赖。
- 新模块保持无 Qt、无 OpenGL、无网络和无文档写盘依赖。
- 更新计划与证据，执行全量 CTest 和 `git diff --check`。

## 验收条件

- 未确认笔触只存在于会话；取消后没有可提交结果。
- 确认后的笔触可完整取回；重放失败只增加失效标记，不丢数据。
- 全量 CTest、架构依赖门禁和 `git diff --check` 通过。

## 明确不在本阶段

真实液化/修复/祛边算法、GPU/OpenGL 着色器、UI 交互、文档写盘、历史记录、账本扣费
和实际 `manual.*` 绘制描述继续保持在后续计划。
