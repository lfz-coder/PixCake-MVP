## 分步任务

### Task 1 — `renderd` 请求生命周期（完成）

- 增加按身份和序号取消待处理请求的接口。
- 保持“只保留最新请求”语义；取消后不能生成帧，也不能误取消新编辑实例的请求。
- 为取消成功、无匹配请求和身份冲突补充测试。

### Task 2 — `exportd` 队列生命周期（完成）

- 让服务在接入 `ExportQueue` 时推进 `排队 → 准备 → 渲染`。
- 未接入解码/编码器时，通过队列的失败事件结束当前尝试；任务仍保留在服务队列中，调用方可先执行 `retry` 再重新处理。
- 服务不写目标文件、不提交半成品，也不改变 `ExportQueue` 的持久化实现。

### Task 3 — 回归门禁（完成）

- 增加上述生命周期测试，并复核服务健康入口。
- 运行独立构建、CTest、架构依赖检查、能力归属检查和 `git diff --check`。
- 更新证据记录，明确本阶段仍未完成真实解码/编码和像素执行。
