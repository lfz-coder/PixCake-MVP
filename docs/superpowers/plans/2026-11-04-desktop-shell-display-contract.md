# 官方手册对齐的桌面壳层与展示契约实施计划

日期：2026-11-04  
状态：本批次已完成（仅壳层展示契约）；F01–F13 未完成、延期处理

## 目标

建立 `ui/shell` 的桌面壳层边界，按官方桌面版手册与 Jarvis 对照应用 9.3.0 的可观察页面，提供登录、主页、图库、精修、创意五个页面的只读展示契约和最小页面导航状态机。

## 证据与约束

- 用户指定的官方工作区页面介绍优先；本批次使用仓库中的桌面阶段设计文档作为已整理的需求基线。
- Jarvis 实测应用：`/Applications/pixcake-test.app`，应用版本 `9.3.0`，页面图存在；精修页 AX 树确认了首页、搜索、图库/精修切换、个人中心、导出、工具栏、缩略图区和功能区。
- 未被手册或 Jarvis 确认的控件、默认值和业务行为不实现。
- 本批次不接入导出提交、账本扣费、源文件删除、历史写盘、像素渲染、GPU、真实窗口和单实例进程。
- F01–F13 审核修复明确标记为“未完成、延期处理”，不作为本批次完成条件。

## 步骤

1. 增加 `ui/shell` 静态库和头文件，定义壳层页面、展示区域、主窗口契约及页面导航边界；保持 `kernel` 不依赖 `ui`。
2. 为五个页面填充已确认的导航栏、全局功能区、工具栏、缩略图区、侧边栏、画布和图层面板展示区域；“常用功能”和“快捷功能”保留为空区域。
3. 增加壳层契约测试，覆盖登录态、项目内页面导航、返回主页和区域顺序/标签；不测试未实现的业务动作。
4. 运行架构门禁、完整 CTest 和新增壳层测试，记录结果。
5. 更新本计划状态与延期清单，报告成果和下一步。

## 完成条件

- `ui/shell` 可独立构建，并且架构检查确认 `kernel` 没有反向依赖。
- 五个页面的区域和标签与设计文档及 Jarvis 证据一致。
- 未实现的 F01–F13 在报告和计划中保持“未完成、延期处理”。

- 已完成：`ui/shell` 静态库、五页展示契约、导航状态机、契约测试、CMake 接入。
- 已验证：`build-shell` 构建成功，CTest 23/23 通过，架构门禁通过。
- 未完成、延期处理：F01–F13 的导出路径安全、文件身份、跨句柄一致性、旧文件迁移、批量性能、历史/恢复、进程协作、真实窗口、渲染和业务动作；这些不属于本批次完成条件。
