# 账号注册、登录与可替换短信适配

状态：本地开发范围实现并验收。用户授权开发环境随机验证码自动填入，后续替换真实短信 SDK；同时实现注册、密码登录及账号生命周期。此授权替代此前“短信保持未配置”的阶段范围。见[账号与同步验收](../evidence/2026-11-10-cloud-auth-and-sync.md)。真实短信和公网部署仍待外部配置。

本模块为 PixCake-specific 账号业务，遵守 C-19/C-22、B-06/B-50、S-06/S-18/S-22/S-25、P-02、Q-05/Q-11/Q-12、T-01–T-07。文件传输与项目快照已按[独立计划](2026-11-10-cloud-file-sync.md)实现；模拟验证码不代表真实短信送达。

| 契约 | 实现与边界 |
| --- | --- |
| AUTH-01 | 后端拥有验证码、账号、密码哈希和令牌。短信 `SmsSender.send` 只负责投递；SDK 更换不修改注册/校验/权限业务。Mock 必须显式启用 development 模式，生产配置拒绝 mock；桌面自动填入另受开发编译开关约束。 |
| AUTH-02 | 随机 6 位码、300 秒有效、60 秒重发间隔、最多 5 次校验；绑定 challenge/手机号/用途，单次使用、重发作废旧码。持久化 HMAC 摘要，不保存明文码。手机号与来源 IP 分别限流，跨进程/重启保留。 |
| AUTH-03 | 显式注册、短信登录、密码登录、短信重置密码。手机号首次限制中国大陆 11 位（与已有产品一致）。密码 15–128 个 Unicode 字符、NFC、最多 512 UTF-8 字节，允许空格及粘贴；拒绝基础常见弱密码，无强制字符拼盘。服务端 Argon2id 随机盐，64 MiB/t=3/p=4，成功登录按需升级哈希；最多 2 个并发哈希任务。 |
| AUTH-04 | 注册原子创建账号、个人空间与凭证。密码错误和未注册返回相同错误；重置密码撤销全部旧会话。访问令牌 1 小时、刷新凭证 30 天绝对到期，均只存摘要；刷新轮换、重复旧凭证撤销同一会话族。退出同时撤销该会话族。 |
| AUTH-05 | JSON 请求最多 4 KiB、拒绝重复键/未知字段/错误类型/超时，错误不回显输入。HTTPS 仍由既有 transport 校验，日志无手机号/密码/验证码/令牌。 |
| AUTH-06 | Qt 页面只发 PageActions；后台请求只用不可变副本。主线程校验 generation，取消/退出后的迟到登录不生效。表单状态与错误文案单一来源；登录成功后打开账号对应项目入口与云目录，退出回登录页。 |
| AUTH-07 | 刷新凭证可由独立系统安全存储适配器保存，桌面数据库不保存秘密；恢复须由服务器重新确认。测试使用内存替身，不能修改用户钥匙串。 |

依赖选择：采用 [argon2-cffi 25.1.0](https://argon2-cffi.readthedocs.io/en/stable/api.html)（MIT），使用官方 Argon2 绑定；对比标准库 scrypt（可用但选用 Argon2id 的现有高层验证/升级 API）与 bcrypt（历史截断/资源模型不作为新账号默认）。参数依据 [RFC 9106](https://www.rfc-editor.org/rfc/rfc9106.html) 的低内存推荐配置和 [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。仅后端 Python 3.12 环境引入，uv.lock 锁发行包与 SHA-256；传递依赖与许可补入 THIRD_PARTY.md，不进入 C++/Qt/kernel。
