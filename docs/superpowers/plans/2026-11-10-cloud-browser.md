# 云目录页面与账号验证接入

日期：2026-11-10
状态：本阶段账号验证、后台客户端及只读云目录页面已验收。后续用户授权开发短信 SDK、完整账号与文件同步，已按[新计划](2026-11-10-cloud-auth.md)及[同步计划](2026-11-10-cloud-file-sync.md)扩展；最新状态见[本轮证据](../evidence/2026-11-10-cloud-auth-and-sync.md)，以下 CBR 条款保留原目录阶段边界。

依据：[云空间契约](../specs/2026-11-09-cloud-space-contract.md)、[API v1](../specs/2026-11-09-cloud-backend-api.md)、[模块计划](2026-11-09-cloud-space.md)。本轮为 2B2 的账号验证/后台请求及阶段 6 的只读目录页面；不把目录视为文件上传完成。

产品已有明确导航、个人/团队空间和目录要求；本轮新增 PixCake 自身的只读目录视图，复用现有导航、主题及文案表，不声称复刻未知的外部产品页面。短信发送保持“服务未配置”，无万能验证码、公开签发令牌或生产开发登录入口。

| 契约 | 行为 |
| --- | --- |
| CBR-01 | 每次目录请求先 GET /v1/account，验证服务端账号、会话到期及与当前账号的一致性，再调用既有 CloudService；账号 ID 不由令牌文件声明，API 不提供的余额/订阅不视为可信返回。整次身份+目录操作共用最多 5 秒预算。 |
| CBR-02 | Qt 主线程只拥有账号与显示状态；后台任务拿不可变请求副本并创建自己的同步服务实例，不跨线程读写 AccountSession/CloudSession。一次最多一个任务，无隐式重试/积压。 |
| CBR-03 | 接收结果前比较账号 generation；退出、重登、切换账号立即隐藏旧结果并丢弃迟到响应。普通网络失败保留上一份完整目录，401/403/身份不匹配清空空间、权限和项目。选择新空间失败不能把旧项目标成新空间项目。 |
| CBR-04 | 云空间成为非项目导航页。展示配置缺失、未登录、加载、空空间/项目、可读空间、无读取权限和网络错误。只显示真实目录元数据，无假项目、上传成功标记或未接入的下载动作。页面只发 PageActions 请求，文案/状态归 ui/shell，控制器编排。 |
| CBR-05 | 现有账号可直接附加云客户端；开发构建可显式从私密令牌文件恢复测试会话，须经服务端验证后才写 AccountSession。该命令行入口只在 PIXCAKE_DEV_PAGES 下编译，发布构建拒绝；凭证不出现在 argv、URL、日志、页面或项目库。 |
| CBR-06 | 客户端析构停止 UI 回调并等待唯一任务退出，资源最长受本次 5 秒预算约束；当前不宣称网络取消已实现。HTTP 功能关闭时仍可显示未配置状态，启用时应用包携带 JSON MIT 许可。 |
