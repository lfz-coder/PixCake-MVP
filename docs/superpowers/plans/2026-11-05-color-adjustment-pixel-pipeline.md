# 色彩调节像素管线并行实施计划

日期：2026-11-05
范围：白平衡、影调、滤镜、配置文件、创意色彩、多图色彩统一、局部调色、后期调色，以及它们在预览/导出中的像素执行。

## 目标

把右侧色彩调节参数从“可保存/可展示”推进到可执行的非破坏性像素管线：

1. kernel 为每个能力提供稳定标识、参数模式、片段读取/写回和绘制描述编译。
2. gpu/render 执行绘制描述，统一服务预览和导出。
3. UI 从 kernel 参数模式生成控件，提交参数并显示最新预览帧。
4. 图层、蒙版、不透明度和混合模式作为渲染输入参与合成，但不把业务字段复制到 GPU 层。
5. 暂不实现 Free 分组：AI 校准、色阶、曲线、HSL、色彩编辑器、颜色分级、可选颜色、细节、颗粒、镜头调整、透视矫正、校准。

## 稳定边界

### kernel

- 能力标识：color.global、color.local、color.post、color.match、color.style。
- 参数模式是范围、步进、默认值和可编辑条件的唯一来源。
- 编译输出只包含通道、程序/处理器标识、参数引用、蒙版引用、混合方式、顺序；不包含 OpenGL 对象。
- 编译函数只读文档，不改写文档。
- RAW 白平衡预设、白平衡吸管和自动分析输出最终写回白平衡片段；AI 校准按钮保持未实现。
- 同一份管线顺序供预览和导出使用。

### gpu/render

- 只依赖 pixcake::gl 公共类型和绘制描述。
- 负责纹理上传、shader/pass 执行、蒙版采样、混合、帧缓冲和同步。
- 不读取用户文件，不解析界面控件，不读取能力私有字段。
- 第一阶段使用 Qt OpenGL 后端；渲染调用点保持可切换到 native 后端。
- 输出带修订号、宽高、行距和 RGBA 格式的预览帧；导出使用任务快照和全分辨率。

### ui

- UI 的 kernel 参数和绘制描述接口由其他进程负责；本计划不修改或重复实现该部分。
- UI 只消费已冻结的参数模式、能力描述、禁用原因和预览帧。
- 不在 Qt 控件中写色彩公式，不维护第二份范围/步进。
- 滑杆拖动更新预览副本；提交时通过既有命令入口写回正式文档。
- 直方图、RGB/Lab 取色和白平衡吸管通过渲染进程/IPC 返回，不从窗口截图反推像素。
- UI 先接入白平衡、影调、滤镜/配置文件和局部/后期调色；Free 分组显示为未实现或不注册。

## 并行工作包

### Worktree A：render-execution

- 不接管正在执行的 kernel 参数和绘制描述接口；只实现接口冻结后的渲染消费侧。
- 补齐 pixcake::gl facade、Qt OpenGL 后端和 render executor 的测试骨架。
- 接入只读输入、图层/蒙版合成输入和预览修订号消费。
- 增加白平衡、影调、滤镜/配置文件的像素管线契约测试；不重复定义参数范围。
- 验证 Free 能力不会被误编译进绘制管线。

### Worktree B：ui-render-contract

- 不修改 UI 的 kernel 参数和绘制描述接口；等待其他进程产出并按其冻结版本接入。
- 根据既有参数模式生成白平衡、影调、滤镜/配置文件、局部调色和后期调色面板。
- 增加渲染请求/预览帧模型和 UI 状态更新。
- 接入白平衡吸管、直方图读数和“效果临时隐藏”交互的接口调用。
- UI 不实现像素算法；所有效果通过既有绘制描述/预览帧接口返回。
- 增加 UI smoke/模型测试，验证控件范围来自既有参数模式且拖动不写盘。

### 集成阶段

- 等参数和绘制描述接口冻结后，先接入 gpu/render 的消费侧，再接 UI。
- 对接口变更只更新共享协议适配，不在本计划内创建第二套字段定义。
- 加入最小 Qt OpenGL 后端和一张合成测试图，验证白平衡、曝光/对比度、滤镜强度、蒙版/混合和图层不透明度。
- 统一预览和导出管线，执行构建、CTest、架构依赖检查和渲染冒烟测试。

## 验收条件

- 修改任意已实现参数能得到带新修订号的预览帧。
- 预览和导出对同一文档快照使用同一管线顺序。
- 白平衡、影调、滤镜和图层合成至少有像素级断言。
- UI 不再维护重复的参数上下限和步进。
- Free 分组不会被误显示为已生效。
- 当前未实现的 import/renderd/native/完整导出链路仍明确标注，不能用静态页面 smoke 代替端到端证据。
