# 云项目文件同步实施计划

日期：2026-11-10。状态：实现、无网络监听双目录集成及真实 TLS + renderd 文件传输验收已完成。用户已明确授权同时实现文件同步、版本冲突与断网恢复。实际范围见[验收记录](../evidence/2026-11-10-cloud-auth-and-sync.md)。

本计划扩展原云空间目录计划；沿用审核总则、分层架构、第三方依赖规范。云协议留在 services 与独立后端，内核只增加通用文档复制/资源重定位和项目事务入口。

## 开工契约

| 编号 | 行为、边界与验收 |
| --- | --- |
| CSY-01 | 快照包括项目名称、原图、星级/旗标/色标、已提交参数、虚拟副本、图层及生成像素。只上传相对资源编号，不上传本地路径、书签、账号凭证、缓存和撤销历史。缺失或损坏资源使整个快照失败。 |
| CSY-02 | 原图按 1 MiB 分块，使用成熟 SHA-256 实现；清单使用已锁定 nlohmann JSON/Pydantic。最多 2000 张原图、8000 个资源、8 GiB 总正文、2 MiB 清单、16 MiB 单参数/图层文件。处理单个文件/分块，不把全部原图或参数读入内存。 |
| CSY-03 | 后端上传会话绑定账号、空间、清单、基础版本；每个请求重新鉴权，write/read 独立。分块只接收清单声明的摘要与精确长度，临时文件原子替换。提交前校验全部块，SQLite 事务内比较基础版本并发布新版本。未提交文件不出现在目录。 |
| CSY-04 | 开始和提交幂等；丢失响应后重试不重复建项目、不重复升版本。版本冲突返回 409，旧版本及本地文件保留。用户可下载远端为新本地项目，或将待上传内容保存为新的云项目，不自动合并/覆盖。 |
| CSY-05 | 下载固定修订号，先到账号专属暂存目录，逐块校验后恢复。路径只接受规范化的资源编号；拒绝路径穿越、链接和未知文件。原图走既有导入准入与 BusinessCommands；项目索引事务成功前不可见。失败回滚索引，不覆盖其他文档/原图。 |
| CSY-06 | 一次一个活动传输；上传快照与下载进度持久化在账号专属目录，不持久化 access token。断网保留进度，重试复用已校验块，重启后可恢复。切账号/退出暂停任务并拒收旧结果。清单固定 HTTPS origin，禁止将缓存中的 URL 当成任意请求目的地。 |
| CSY-07 | UI 提供本地项目选择、上传、下载、进度、暂停/继续、冲突另存；成功才标记云端关联。大文件 I/O 与网络在工作线程；账号代数和 UI 完成回调在拥有者线程。 |
| CSY-08 | 验收覆盖双目录上传下载并重新打开参数/副本/图层、分块中断与重启、并发版本冲突、幂等提交、撤权、损坏块、非法路径、磁盘/解析失败和未登录写入拒绝。日志只记录操作/结果，不记录凭证或项目正文。 |

资源上限是实现的防御边界，不是产品订阅配额。暂存上传保留 7 天；单账号最多 4 个未完成上传，全部版本及暂存内容有 50 GiB 防御总上限。正式多实例对象存储和部署另行验收。

断网最多自动重试 3 次，每次间隔 30 秒，之后手动继续。清除上传任务通过幂等 DELETE 释放服务端未提交分块；断网、清理响应丢失或进程重启时保留清理意图，不重新上传。每次新任务用系统安全随机数生成独立 nonce，避免相同内容另存时复用旧幂等键。下载事务使用持久化导入回执避免重复项目，崩溃留下的文档仅允许按预期字节一致接纳，绝不覆盖不同文档。

清理权限例外：DELETE 必须重新验证会话及任务账号所有权，但不要求仍拥有空间写权限。撤权后可清理自己未提交的任务，不能修改、读取或删除已发布版本；其他账号始终无权清理该任务。避免撤权把客户端永久困在待传状态。

## 选型

- 文件封装比较 ZIP/libarchive 与内容寻址分块：采用分块清单，不引入压缩/解压引擎，原图不二次压缩；可断点续传，且不需要解压不可信路径。清单/事务属于 PixCake 业务代码。
- 哈希比较新增 OpenSSL 与系统 CommonCrypto：macOS 采用系统 CommonCrypto 的 SHA-256，经独立 platform 适配器提供普通 C++ 接口；后端采用 Python hashlib。没有手写密码学。系统 SDK 版本随既有构建工具链记录。
- JSON/HTTP/SQLite 复用已锁定的 nlohmann、系统 curl、既有 SQLite 和 Python 后端依赖，不新增运行时包。
